## 二、各模块 DoD（完成定义）与测试实例

**M1 MCP Server**
- DoD：MCP 握手成功；五个工具入参/出参过 schema 校验；意图解析单测（"五一杭州飞成都800以内"→ 正确 route 配置）；E2E：任一 Agent 会话一句话建监控 → snapshot 出现该线路。
- 测试实例：①握手自测脚本 ②意图→config 10 组单测 ③watch_add 写入 config 后 acceptance 全绿。

**M2 源健康自愈**
- DoD：注入模拟故障（改坏端点）后 1 个轮询周期内检出并降级标记；UI 显示降级徽标；生成含候选原因的诊断报告；真实源恢复后自动解除。
- 测试实例：①故障注入单测 ②健康分计算单测 ③诊断报告结构断言。

**M3 反向搜索**
- DoD："¥X 以内从 A 出发"返回目的地列表（含税口径、带数据新鲜度标记）；单次查询总请求数 ≤ 限速预算。
- 测试实例：①预算过滤单测 ②请求预算计数单测 ③API 契约测试。

**M4 洞察周报**
- DoD：周报中每个数字可从 snapshot 重算一致；推送可关闭；语言为自然中文。
- 测试实例：①统计口径单测 ②周报数字与 snapshot 一致性(G4 扩展)。

**M5 插件生态**
- DoD：新数据源只需实现适配器接口 + 通过回放夹具，不改动核心代码。
- 测试实例：①示例适配器过夹具 ②夹具数据与真实响应结构 diff 为空。
- 状态：✅ 2026-09-10 交付（core/adapters.py 接口+注册表+一致性校验；
  qunar-calendar / qunar-intl / amadeus-intl 三个现有源已包装注册；
  tests/test_adapters.py 8 用例 + 3 回放夹具全绿；接入指南见 adapters.py 模块头）。

## 五、研究归档区（探针结论，持续追加）

**v0.11 无价日期与时刻源研究（2026-09）**：去哪儿 H5 按日航班列表需 Bella 签名（红线，放弃）；携程 PC/H5 全 432 保护；飞常准 406/502；Aviasales 免Key日历已下线 404。结论：部分日期源端本身无价（郑州/曼谷），合规方案为两侧真实价插值（v0.11 已上线）；真实起降时刻唯一合规通道为 Amadeus（可选，涉隐私可不接）。

**M5 适配层落地面（2026-09-10）**：统一入参 FetchQuery（城市+区间+税费+密钥+缓存目录）；校验器 validate_deals 同时服务测试与运行时（日期格式/区间/正价/source 对齐/排序五断言）；ReplayAdapter 支持离线回放，新源开发不依赖外网。已知边界：train 适配器接口已定义（TrainSourceAdapter）但 12306 包装待 M5.1，编排层（crawl/travel）切换到适配器调用待 M5.2。

**v0.18 航班时刻零密钥源研究（2026-09-10）**：萧山机场官网「航班信息」页使用公开只读接口 apisys.h22.66571.com/api/leave_import/hbh/ 与 /arrive_import/hbh/（需 Referer: www.hzairport.com/flight/index.html，浏览器同源、无签名无验证码）；字段 hbh=航班号、main_hbh=共享号、jhsj=计划时间（出发板=起飞/到达板=落地）、preschtime=前站计划起飞、chinese_sfcs/mdcs=城市、chinese_hs=航司。方案：每日低频抓当日双板（6h 落盘缓存，日请求≤2），按「航班号+星期几」沉淀周班期参考时刻库（core/sched_board.py），到达板双时刻优先于出发板仅起飞；约一周自然覆盖 60 天日历内各航班的计划起降。时刻为航季计划参考（非实时验证），仅展示不打扰提醒逻辑；配置 Amadeus 后自动让位实时刻。否决项：重庆机场官网域名已停放不可用；AviationStack 免费套餐仅实时状态无未来时刻表。

**v0.18 复核修复（同日，双 agent 评审驱动）**：① 合并逻辑改「双时刻行整条替换、残缺行只填不删」，杜绝到达板缺 preschtime 时抹掉已存起飞时刻；② 每板每日≤2 次真实请求由计数文件（board_fetch_log）硬性落地，失败尝试同样计数（端点故障不会变成 45 分钟重试风暴），超限服务陈旧缓存，force 可越过；③ 库与缓存改原子写（tmp+os.replace，pid 后缀防互踩），读到坏库先备份 .corrupt-* 再重建，跨进程不再互毁；④ 推送渠道非 200 / ServerChan 错误体显式标 ERR（BODY code 与 HTTP 区分），周报全渠道失败写 6h 退避，部分成功消耗计时器并告警；⑤ 相关性门读 config 真实键 from_city/to_city（提成 touches_hangzhou 可测函数+回归用例，修复首版误读 from/to 导致恒 skip 的 P1），非杭州线路记 skip 省请求预算。新增 test_notify.py 与 guardrails/退避/门控用例，测试 35 项全绿。

**v0.19 跨日班期时刻补全（2026-09-10）**：实测 v0.18 覆盖极差的根因——班期库首周仅有当日 dow 数据（snapshot 中杭州-重庆 60 deals 仅 4 条 dep_time、0 条 arr_time），且官网接口无日期维度：页面 JS 只按 keywords=航班号搜索（jedate 只加载未使用），探测 ?date=2026-09-13 传参被忽略（返回仍是当日板）、路径段 /hbh/2026-09-13/ 按 keywords 处理（flag=-1 rows=0），**按日期回填方案否决，勿再消耗请求探测**。替代方案：低价日历已证明该航班号在该日期执飞，同号航班时刻按航季排班跨星期高度一致 → board_lookup_x 先精确 dow、未命中则跨 dow 借用（城市校验 + 双时刻条目优先），time_src=airport-board-x 打「跨日班期·参考」徽标；出发板只含起飞（HGH 出发板的 arr 永远不会有，落地属到达板特性），故仅有起飞时新增 arr_est 字段按大圆+约 40 分钟滑行/爬升（代码 0.7h）估算落地（跨零点回绕，~ 前缀 + 虚线样式 + 悬停说明），独立字段不写入 arr_time 防混源；中转行程同样走跨日借用且估算含 2.5h 中转，跨段徽标取弱标记（任一段借用即标跨日）。时刻纯展示不影响提醒/统计（红线#4 满足）。新增 board_lookup_x 7 项 + 估算/序列化 2 项单测，全套 42+8 全绿。

**v0.20 真 PWA + 时刻库透明度（2026-09-10）**：部署丰富度补齐——manifest 此前仅有 SVG 图标（iOS apple-touch-icon 不支持 SVG → iPhone 添加主屏后图标空白），无 Service Worker（无离线壳）。tools/gen_icons.py 用 PIL 以 4x 超采样绘制主题色渐变底+纸飞机，产出 icon-512/192/180/32.png 与 maskable-512/192.png（内容收进 78% 安全区），提交进仓库可复现；sw.js 以 fare-alert-v20 缓存桶实现 /static/* 缓存优先（URL 带 ?v= busted，升级即失效）+ /api GET 网络优先+缓存兜底（离线可读最近一屏数据，无缓存时返回 503 JSON）+ navigate 网络优先+缓存兜底（离线可冷启动 UI），非 GET 与跨域一律放行，activate 清旧桶，cachePut 失败静音防 unhandled rejection。新增 /api/sched-stats（core.sched_board.sched_stats 纯函数：非空条目才计数，避免进度条撒谎）+ 数据源页七天沉淀进度 widget（周一~周日高亮已沉淀天数+航班数），把「为什么这天没有精确时刻」从隐性知识变成显性 UI；周报推送无渠道报错时前端自动 gotoTab(push) 并高亮 Bark 输入框（推送引导闭环）。双 agent 验收（E2E 5/5 + 评审 0 P0/P1，P2 当轮修 4 项）。单测 44+8 全绿。已知遗留：mcp_selftest 对真实 config.json 做 add→del 恢复检查，与并发验收互跑会撞出假 FAIL（本轮两次实锤），下轮加文件锁或临时 config 副本隔离。
