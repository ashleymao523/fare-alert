## 一、项目从哪来（需求原点，2026-09-08）

用户想监控**杭州→重庆未来 60 天**的机票最低价：含机建燃油的**最终支付口径**、单程 1 人、低于心理价位即推送（Bark/微信）、同步对比 12306 全席位含学生票、标注免费托运、点击直达购票页。部署在私人设备（Win 台式机为主，Mac/iPhone 可迁移），后续泛化为任意线路的"出行最优"低价提醒组件，并开源到 GitHub。

## 三、用户偏好与协作方式（照做，别重新发明）

1. 中文交流；**每轮按固定格式汇报**：问题诊断 / 成果 / 验收证据 / 下一步。
2. **实弹验收**：真实采集证据优先于单测绿灯；UI 改动跑 `tools\dump_dom.cmd` + `tools/ui_check.py`。
3. 每完成一个阶段立即 commit + push（`vX.Y: 摘要` 或 `eng: ...`）。
4. 电脑卡顿敏感：**服务用完即停**，不留后台爬虫；曾因残留 230 个 python 进程被要求清理。
5. 隐私敏感：Amadeus 注册被要求工作邮箱+公司即放弃，转无 key/自建通道；密钥永不入库。
6. UI 审美取向：Skyscanner 式亮色、克制、信息密度高；反复否定暗色与"AI 感"渐变图表。

## 四、环境红线（Windows 本机实踩，新会话必读）

- PowerShell 5：无 `&&`、无 heredoc；复杂逻辑写临时 py 脚本（`Set-Content @'...'@` + `python -X utf8`）。
- **中文文件名 `git add` 在 PowerShell 会静默失败**：用 `python -c "import subprocess; subprocess.run(['git','add','--','中文.md'])"`。
- **直连 `git push` TCP 重置**，唯一通道：`python -X utf8 tools/api_push.py`（要求工作区干净）。
- `git ls-files` 默认八进制转义中文：打包脚本已用 `-c core.quotePath=false` 修复。
- `Stop-Process -Force` 被策略拦截，裸 `Stop-Process -Id` 可用；复合命令偶尔被拦需拆单步。
- exec 单次 ~30s 墙：长任务 `Start-Process -RedirectStandardOutput` 后台跑再轮询。
